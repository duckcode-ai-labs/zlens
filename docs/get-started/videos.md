# Video tutorials

Short videos, about a minute each, on the
[ZLens YouTube channel](https://www.youtube.com/@zlensanalytics){ target=_blank rel=noopener }.
Each one shows a single task from start to finish. The docs page linked under
each video has the same steps as text.

New to ZLens? Watch the 90-second film, then the five Quick Start videos in
order.

Most videos were recorded on ZLens 0.2.x, and the newest on 0.3.0. Where a
screen has changed since, the note under the video says what is different now.
